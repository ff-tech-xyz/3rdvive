Overview
3rdVive is a client-side Vivecraft add-on with a common module and a jar for each of Fabric and NeoForge. It is built on the 26.2 branch of MultiLoader-Template, which uses the same common + per-loader layout as Vivecraft itself.

Repositories (buildSrc/multiloader-common.gradle)
repositories {
    maven { url = 'https://api.modrinth.com/maven' ; content { includeGroup 'maven.modrinth' } }
    maven { url = 'https://maven.bawnorton.com/releases' }
}
Dependencies
// common/build.gradle
compileOnly "maven.modrinth:vivecraft:${vivecraft_version}-fabric"
compileOnly annotationProcessor("com.github.bawnorton.mixinsquared:mixinsquared-common:${mixinsquared_version}")

// fabric/build.gradle  (26.x is unobfuscated: plain implementation, no modImplementation)
implementation "maven.modrinth:vivecraft:${vivecraft_version}-fabric"
include(implementation(annotationProcessor("com.github.bawnorton.mixinsquared:mixinsquared-fabric:${mixinsquared_version}")))

// neoforge/build.gradle
implementation "maven.modrinth:vivecraft:${vivecraft_version}-neoforge"
compileOnly annotationProcessor("com.github.bawnorton.mixinsquared:mixinsquared-common:${mixinsquared_version}")
jarJar(implementation("com.github.bawnorton.mixinsquared:mixinsquared-neoforge:${mixinsquared_version}"))
thirdvive.mixins.json (common)
Priority 1500 makes these apply after Vivecraft's (default 1000), so the methods Vivecraft adds already exist.
{
  "required": true,
  "minVersion": "0.8",
  "package": "com.thirdvive.mixin",
  "compatibilityLevel": "JAVA_25",
  "mixinPriority": 1500,
  "client": [
    "MinecraftMixin",
    "MinecraftToggleKeyMixin",
    "CameraMixin",
    "vivecraft.RenderHelperMixin",
    "vivecraft.VREffectsHelperMixin",
    "vivecraft.RenderPassMixin",
    "vivecraft.VRArmHelperMixin"
  ],
  "injectors": { "defaultRequire": 1 }
}

Entrypoints
File
Job
ThirdViveFabric.java
implements ClientModInitializer; calls ThirdVive.init()
ThirdViveNeoForge.java
@Mod(value = ThirdVive.MOD_ID, dist = Dist.CLIENT); calls ThirdVive.init()
ThirdVive.java
Loads ThirdViveConfig, logs the detected Vivecraft version
What each mixin does, and how, is in the companion developer spec.
